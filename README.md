# Prism Entertainment website

Source for prismentmt.com: a static, mobile-first site served by GitHub Pages. No build step; edit the HTML files directly.

- `index.html` home, `produce.html`, `develop.html`, `work.html`, `start.html` (inquiry form), `privacy.html`, `404.html`
- `assets/site.css` styles and brand tokens, `assets/site.js` menu, work filters, video player, inquiry form
- `assets/brand/` logo files extracted from the Prism logo pack

Staging notes: text highlighted yellow is placeholder copy. The yellow banner and the `noindex` tag come out at launch.
